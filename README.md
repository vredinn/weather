## Приложение погоды на VueJS
Приложение отображает погоду в выбранном городе (5 вариантов)

# Инструменты
- VueJS - frontend фреймворк
- openweathermap - API для получения данных о погоде

# Функции
- Выбор города (Нижний Тагил, Алапаевск, Екатеринбург, Санкт-Петербург, Москва)
- Выбор языка (Русский, Английский)
- Выбор единиц измерения (Цельсий, Фаренгейт, Кельвин)
- Отображение текущей погоды
- Отображение прогноза погоды на 5 дней
